# Multiplication Table Generator (Java)

## About the Project
Multiplication Table Generator is a menu-driven Java console application that generates multiplication tables for a single number or a range of numbers.

This project was developed as part of the Java Programming Internship at Veda Technology.

## Features
- Generate multiplication table for a single number.
- Generate tables for a range of numbers.
- Formatted console output.
- Separate methods for table generation.
- Nested loops for multiple tables.
- Basic range validation.

## Technologies Used
- Java
- JDK 23
- IntelliJ IDEA

## Java Concepts Used
- Methods
- For Loops
- Nested Loops
- Switch Case
- If-Else Statements
- Scanner Class
- printf() for formatted output

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Open `Main.java`.
4. Run the Main class.
5. Select an option from the menu.
6. Enter the required number or range.

## Application Menu

1. Generate Single Table
2. Generate Tables in Range
